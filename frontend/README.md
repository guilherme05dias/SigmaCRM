# Frontend legado

Esta pasta contém implementações anteriores do SigmaCRM.

## Conteúdo

- `web/`: aplicação Next.js antiga.
- `streamlit/`: aplicação Streamlit antiga.

## Regra atual

Não desenvolver novas funcionalidades aqui.

O desenvolvimento novo deve acontecer em:

```text
SigmaAtendimento/apps/web/
```

Esta pasta deve ser usada apenas para consulta, comparação ou migração controlada de ideias/componentes.
